Aria ERP

A free, open-source, modular ERP for small and mid-sized businesses. Asset management with depreciation, inventory, CRM and HRMS in one TypeScript application you can run and modify yourself.

Modules

One suite, separate workspaces

Each module is its own workspace in the same app, sharing users, roles and an admin console. Asset management and inventory are the most complete today.

Available

Asset management

Asset register with categories and locations, maintenance logs and teams, value adjustments, and scheduled depreciation with ledger and balance reports.

Available

Inventory

Items, variants and groups, warehouses, units of measure, serial and batch numbers, purchase, sales and transfer orders, and stock reports.

In progress

CRM

Planned: customer database, lead tracking, sales pipeline and communication history. The workspace exists; most features are still to come.

In progress

HRMS

Planned: employee management, attendance, leave and payroll. The workspace exists; most features are still to come.

Windows demo

Try the demo on Windows

Aria ERP Setup runs the full stack in Docker, with demo inventory and asset data if you want it. No Git, clone or build needed. Windows 10 or 11, about 4 GB of memory for Docker and 15 GB of free disk.

  1. Install Docker Desktop

    Install Docker Desktop (needs administrator rights), start it once and enable Start Docker Desktop when you sign in.

  2. Run Aria-ERP-Setup.exe

    Download Aria ERP Setup and run it. It needs no administrator rights, shows each step in one window and can open Aria when it is done.

  3. Open Aria

    Use the Aria ERP shortcut, or go to http://localhost:8080.

  4. Sign in

    Username admin, password admin123.

Update

Open Aria ERP Setup from the Start menu and click Check for updates. It backs up the database first and rolls back automatically if the update fails.

Uninstall

Open Aria ERP Setup from the Start menu and click Uninstall. You choose whether to keep the database backups.

"Windows protected your PC"? SmartScreen can warn about a new download. Click More info, then Run anyway. Aria ERP Setup is built by GitHub Actions from this repository; code signing through SignPath Foundation is being set up under the code signing policy. Full details in the setup guide.

For developers

Run it from source

A Bun and Turborepo monorepo: NestJS API, Next.js frontend and shared packages for types and the tRPC contract. You need Bun 1.3+, Node.js 20 or 22, and PostgreSQL 16+ (or Docker).

Quick start 
# Clone and install
git clone https://github.com/Karthik-beta/Aria.git
cd Aria
bun install

# Start development
bun --filter backend start:dev  # API on :3001
bun --filter frontend dev       # App on :3000
