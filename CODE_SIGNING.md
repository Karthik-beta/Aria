# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io/), certificate by
[SignPath Foundation](https://signpath.org/).

## What is signed

Only Aria ERP Setup for Windows, `Aria-ERP-Setup.exe`, attached to each
[GitHub Release](https://github.com/Karthik-beta/Aria/releases). Nothing else in this
repository is distributed as a signed binary.

Every signed `Aria-ERP-Setup.exe` is:

- built from this repository's source by GitHub Actions, on GitHub-hosted runners
  (`.github/workflows/release-images.yml` calling `.github/workflows/windows-installer.yml`)
  for a `vX.Y.Z` tag;
- submitted to SignPath by that same workflow run, which verifies that the file came
  from this repository and workflow (see `.signpath/artifact-configuration.xml`);
- signed only after a maintainer manually approves that release's signing request.

Builds from forks, pull requests and local machines are never signed. The uninstaller
that setup places on disk (`unins000.exe`) is generated by Inno Setup at install time and
is not signed.

## Privacy policy

This program will not transfer any information to other networked systems unless
specifically requested by the user or the person installing or operating it.

- **Setup and updates.** Aria ERP Setup and `aria-local.ps1` download the Aria
  container images from the GitHub Container Registry (`ghcr.io`), and the base images
  they need from Docker Hub, through Docker Desktop. **Check for updates** in Aria ERP
  Setup asks the GitHub API (`api.github.com`) for the latest release, and **Update**
  downloads the newer `Aria-ERP-Setup.exe` from GitHub; both happen only when you click
  them. None of this sends data about you or your business. GitHub's and Docker's
  privacy policies apply to them:
  [GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement),
  [Docker](https://www.docker.com/legal/docker-privacy-policy/).
- **The app.** Aria runs entirely on your computer at `http://localhost:8080`. Its data
  stays in the local PostgreSQL database and the backups folder. Error reporting
  (Sentry) is off unless an operator sets `NEXT_PUBLIC_SENTRY_DSN`, and outgoing email
  is off unless an operator configures SMTP.
- **Docker Desktop** is a separate product installed by you, with its own
  [privacy policy](https://www.docker.com/legal/docker-privacy-policy/).

## Reporting misuse

If you believe a binary signed under this policy is malicious or was not built from this
repository, report it as described in [SECURITY.md](./SECURITY.md) and to
[SignPath Foundation](https://signpath.org/).
