# Aria ERP

Aria ERP is an open-source, self-hostable ERP for small and mid-sized businesses. Its core business logic is ported from [ERPNext](https://github.com/frappe/erpnext) and rebuilt on a TypeScript stack: a NestJS + tRPC + Prisma backend, a Next.js frontend and PostgreSQL.
