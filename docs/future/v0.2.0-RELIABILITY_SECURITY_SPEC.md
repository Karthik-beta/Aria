#### 2.2.3 Cross-Platform Implementation
**Linux Implementation**:
```bash
# /opt/aria-erp/scripts/backup-manager.sh
#!/bin/bash
set -euo pipefail

# Auto-detect storage
detect_backup_storage() {
    # USB devices
    for device in /media/* /mnt/*; do
        if [[ -d "$device" && -w "$device" ]]; then
            echo "external:$device"
            return 0
        fi
    done
    
    # Network storage
    if mountpoint -q /mnt/network-backup; then
        echo "network:/mnt/network-backup"
        return 0
    fi
    
    # Local fallback
    echo "local:/opt/aria-erp/backups"
}
```

**Windows Implementation**:
```powershell
# C:\Program Files\AriaERP\scripts\backup-manager.ps1
function Detect-BackupStorage {
    # USB/External drives
    $externalDrives = Get-WmiObject -Class Win32_LogicalDisk | 
        Where-Object { $_.DriveType -eq 2 -and $_.FreeSpace -gt 1GB }
    
    if ($externalDrives) {
        return "external:$($externalDrives[0].DeviceID)"
    }
    
    # Network drives
    $networkDrives = Get-PSDrive -PSProvider FileSystem | 
        Where-Object { $_.DisplayRoot -like "\\*" }
    
    if ($networkDrives) {
        return "network:$($networkDrives[0].Root)"
    }
    
    # Local fallback
    return "local:C:\Program Files\AriaERP\backups"
}
```

        reservations:

      retries: 3

**Monitoring Script Example**:
```bash
#!/bin/bash
# Memory monitoring with automatic container restart
MEMORY_THRESHOLD=400  # MB
CONTAINER_NAME="aria-backend"

get_container_memory() {
    docker stats --no-stream --format "{{.MemUsage}}" $CONTAINER_NAME | 
    awk '{print $1}' | sed 's/MiB//'
}

monitor_memory() {
    local current_memory=$(get_container_memory)
    if (( current_memory > MEMORY_THRESHOLD )); then
        echo "Memory threshold exceeded: ${current_memory}MB"
        docker restart $CONTAINER_NAME
        log_event "Container restarted due to memory threshold"
    fi
}
```

openssl genrsa -des3 -out AriaCA.key 4096

#### 4.2.3 Installation Package Security
**Implementation**: Secure packaging with integrity verification

**Package Structure**:
```
aria-erp-v0.2.0/
├── checksums/
│   ├── SHA256SUMS                  # File integrity checksums
│   └── SHA256SUMS.sig              # Signed checksums
├── certificates/
│   ├── aria-ca.crt                 # Certificate Authority
│   └── aria-codesign.crt           # Code signing certificate

```

**Verification Process**:
```bash
#!/bin/bash
# Pre-installation security verification
verify_package_integrity() {
    echo "Verifying package integrity..."
    
    # Verify checksums
    if sha256sum -c checksums/SHA256SUMS; then
        echo "✓ Package integrity verified"
    else
        echo "✗ Package integrity check failed"
        exit 1
    fi
    
    # Verify signatures
    if openssl dgst -sha256 -verify certificates/aria-codesign.crt \
        -signature checksums/SHA256SUMS.sig checksums/SHA256SUMS; then
        echo "✓ Digital signature verified"
    else
        echo "✗ Digital signature verification failed"
        exit 1
    fi
}
```

## Appendix: Interim Solutions (Until v0.2.0)

While v0.2.0 features are being developed, consider these workarounds:

### Simple Backup Script
```bash
#!/bin/bash
# deployment/scripts/simple-backup.sh
BACKUP_DIR="/opt/aria-erp/backups"
DATE=$(date +%Y%m%d_%H%M%S)

mkdir -p "$BACKUP_DIR"
docker exec aria-database pg_dump -U aria aria > "$BACKUP_DIR/aria_$DATE.sql"
tar -czf "$BACKUP_DIR/config_$DATE.tar.gz" /opt/aria-erp/.env
echo "Backup completed: $BACKUP_DIR"

# Keep only last 7 backups
ls -t "$BACKUP_DIR"/*.sql | tail -n +8 | xargs rm -f 2>/dev/null
```

### Basic Monitoring
```bash
#!/bin/bash
# Check container health every 5 minutes via cron
# */5 * * * * /opt/aria-erp/scripts/simple-health-check.sh

CONTAINERS="aria-proxy aria-database aria-backend"
for container in $CONTAINERS; do
    if ! docker ps | grep -q "$container"; then
        echo "Container $container is down! Restarting..."
        cd /opt/aria-erp && docker compose restart $container
    fi
done
```
